# Lila 生活指南

无需安装依赖的静态网站，包含生活指南、30 题认定考试和合格证书下载。

## 本地预览

```sh
python3 -m http.server 4185 --bind 127.0.0.1
```

打开 http://127.0.0.1:4185 。

## 考试与证书

- 每次随机抽取 10 题，题目不重复，选项也会乱序。
- 每题 1 分：0–3 分是 Lila 的生气提示，4–7 分鼓励重考，8–10 分合格。
- 合格后可填写称呼（选填）、预览并下载 A4 横版 PDF。
- 证书包含成绩、Lila 签名、爪印和东京时区的下载日期。
- PDF 在浏览器本地生成，不需要邮件服务，也不会上传填写的名字。
